# 星源·所愿 PET · DeepSeek Harness

透明背景的交互桌宠，支持动作、形态切换、拖动定位与右键费用对话框。

**v0.1.0 · 2026-11-27**  
适用于 DeepSeek Harness >= 0.2.0，验证环境为 Windows 桌面版 0.2.2-rc.5。

## 安装

在 **插件 → 添加插件** 中粘贴：

```text
github:Glazyon/dsh-shuguang-wish-pet#v0.1.0
```

安装后刷新或重启客户端。

想一起安装四套皮肤及三只 PET，请使用 [星源主题套装](https://github.com/Glazyon/dsh-shuguang-skin)：

```text
github:Glazyon/dsh-shuguang-skin#v0.1.0
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 单击 | 播放当前形态的动作 |
| 双击 | 切换形态；转换过程中的动作受保护 |
| 拖动 | 移动桌宠并保存位置 |
| 右键 | 打开/关闭费用与用量对话框 |
| Esc / 点击面板外部 | 关闭对话框 |

使用原生 WebP 动画，动作约 60fps。右键费用面板读取宿主账户余额，今日花费为本机估算，最终以平台账单为准。未登录、数据不可用或尚未记录时会明确显示未获取/暂无统计。
独立安装时，本机用量统计需要主皮肤提供相应服务；账户余额仍通过宿主账户服务读取。

普通形态与 skill3 的原点已固化到动画素材中，切换沿用同一脚底基准。
